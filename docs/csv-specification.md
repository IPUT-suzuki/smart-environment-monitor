# CSV仕様

## `sensor_data.csv`

UTF-8、CSV標準改行で保存します。列順は固定です。

| 列 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| client_id, region, datetime, session_id | 文字列 | はい | 送信元・計測時刻・セッション |
| sequence | 正整数 | はい | セッション内の送信番号 |
| temperature | 有限数・小数第1位まで | はい | 温度 |
| humidity | 有限数・小数第1位まで | はい | 湿度 |
| pressure | 有限数・小数第1位まで | はい | 気圧 |
| co2 | 整数 | はい | CO₂ |

TCP保存とWeb手動登録のどちらも4測定値全てが必須で、センサーノードの型・桁数に統一します。Web手動登録の温度・湿度・気圧は小数第1位の文字列表現で保存します。ダウンロードCSVは同じ列順でUTF-8 BOMを付加します。

## `health_history.csv`

UTF-8の履歴CSVです。`received_at`、端末ID・地域、各センサの読取状態・回数・時刻・エラー、送信状態、ヘルス送信状態、ランタイム状態を保存します。旧ヘッダーを検出した場合は共有ロック中に一時ファイルへ移行して置換します。

共有CSVのロックは`<CSV名>.lock`ディレクトリです。異常終了で残った空ロックは60秒後（設定変更可）に回復対象になります。
