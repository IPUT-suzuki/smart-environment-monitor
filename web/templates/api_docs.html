OVERVIEW

APIの使い方

JSON APIは成功・失敗ともにJSONを返します。CSV APIはUTF-8 BOM付きCSV、 ストリームAPIはServer-Sent Eventsを返します。

01

取得

GET APIで測定値や端末状態を取得します。

02

登録

POST APIへJSONを送り、測定値やヘルスを保存します。

03

更新検知

SSEでヘルス状態の更新をリアルタイムに検知します。

COMMON RESPONSES

共通ステータス

2xx正常終了。POSTによる作成は201です。

404指定端末のヘルス履歴がありません。

測定データを手動追加

application/json

1回のリクエストで1行以上を登録します。各行は個別に検証され、全行が有効な場合だけ保存します。

dry_run=true なら保存せずに検証 APIページの実行欄は、この安全な検証モードが初期設定です。

リクエストボディ

フィールド必須仕様
rows必須空ではない配列。各要素は次の4項目だけを持つobject
rows[].temperature必須number（°C）・小数第1位まで
rows[].humidity必須number（%）・小数第1位まで
rows[].pressure必須number（hPa）・小数第1位まで
rows[].co2必須integer（ppm）

登録成功 — 201

{
  "rows_added": 2,
  "session_id": "web-manual-<UUID>"
}

検証成功（dry_run=true）— 200
