# server仕様

TCP受信サーバーは改行までバッファリングしてJSONを復元し、必須文字列、正整数連番、4測定値を検証します。温度・湿度・気圧は有限数かつ小数第1位まで、CO₂は有限な整数で、欠損や未知の測定フィールドを拒否します。受理後、`client_id`・`session_id`・`sequence`で重複判定して測定CSVへ追記します。

CSVの読取・スキーマ移行・追記は`common.csv_lock.csv_lock`で保護します。ロック取得期限を超えた場合はTCP接続へ`ok:false`の再送可能なエラーACKを返します。各クライアント接続は別スレッドのため、不正JSONや切断は他接続を止めません。
