# client仕様

`main`モードはDHT22、BME280、MH-Z19Cを各周期で読みます。全値が有限数かつ揃った場合だけ、端末ID、地域、JST日時、UUIDセッションID、連番、4測定値のJSON LinesをTCP送信します。ACKのセッションID・連番不一致は送信失敗です。

読取失敗時は失敗したセンサだけのヘルス回数を増やし、完全な測定スナップショットは送信しません。連続失敗は設定しきい値で一度だけDiscordへ通知し、復旧時に一度だけ通知します。ヘルス送信周期は測定周期と独立です。

実機センサの配線、タイムアウト、通知設定は[セットアップ](./setup.md)を参照してください。
